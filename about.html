Making machine learning more human.

SirenSense is an educational TinyML prototype exploring how a phone can recognize an emergency siren locally and translate sound into clear visual and haptic cues.

So, what is TinyML?

TinyML means running machine-learning models on resource-constrained devices: phones, microcontrollers, and other edge hardware. Instead of sending every input to a remote server, a compact model makes a prediction where the data was captured. Thoughtful model design, compression, and efficient computation help keep storage, memory, energy use, and response time modest.

◉

Private by design

Audio features are calculated in the browser and predictions stay on the device. This prototype does not upload microphone recordings.

⌁

Fast, local response

No round-trip to a cloud service is needed for inference, so a trained model can respond with low latency and without network access.

▣

Designed to be small

A compact CNN and quantized model weights target a few megabytes, making browser delivery and on-device execution practical.

From street sound to an alert

This is the end-to-end workflow—from labeled examples to a browser-side decision. The pipeline is reproducible with the training script in training/. No trained weights are bundled: the live app uses a clearly labeled experimental tone-sweep fallback until a real model is trained and installed.

Dataset

UrbanSound8K has 8,732 short urban recordings across ten sound classes. Siren is class 8. The training script creates a binary siren / not-siren task.

Preprocess

Convert audio to mono 16 kHz, cut or pad to 1 second, calculate 64-band log-mel spectra, then standardize each window.

Train a small CNN

Two lightweight convolution blocks and global pooling learn patterns in time and frequency. Validation data is held out by source fold.

Evaluate

Check recall, precision, and false alarms on held-out clips. Thresholds should be calibrated on representative real-world recordings.

Optimize

Export with 8-bit quantized weights to reduce download size. Pruning can be explored, but needs fine-tuning and a compatible conversion path.

Convert

TensorFlow.js converter packages the Keras model for browser execution. The web app expects a softmax output ordered [not siren, siren].

Run on device

The Web Audio API captures overlapping 1-second windows at 0.5-second intervals. Local JS mel features feed the model in TensorFlow.js.

Alert accessibly

Two consecutive above-threshold predictions trigger a prominent banner and optional vibration. The alert clears when confidence falls.

What happens in this browser?

Microphone capture requires a secure context (HTTPS or localhost) and permission. With trained weights installed, samples are resampled to 16 kHz, transformed into log-mel frames, normalized, and passed to the TensorFlow.js model. Without weights, an experimental local signal-processing fallback looks for a strong tone that sweeps in pitch; this is a heuristic, not machine learning, a siren probability, or a validated detector. The frontend stores only user preferences in local storage. Neither the sample buffer nor uploaded demo clips are transmitted. The live audio graph is stopped when listening stops or the page is left.

Accessibility, impact & limitations

Deaf and hard-of-hearing people should not have to rely on hearing to notice important surroundings. Making a sound class visible and tangible could support more inclusive mobility, aligning with UN Sustainable Development Goal 10: Reduced Inequalities. Co-design with deaf drivers and accessibility specialists is essential; a prototype is not a substitute for lived experience or professional safety evaluation.

Safety first. SirenSense is a learning demonstration, not a certified driver-assistance or emergency-warning system. It can miss sirens or produce false alerts, especially with traffic, music, blocked microphones, device placement, or different siren styles. Never use it to decide whether to yield, replace mirrors, or override local road rules. Keep attention on driving and stop safely before interacting with the phone.
